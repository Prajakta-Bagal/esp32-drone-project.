ⓘ About PMS7003 Dashboard

This dashboard monitors PM1.0, PM2.5 and PM10 readings and uses K-Means clustering to classify pollution levels.

  • Live readings from the ESP32 + PMS7003
  • CSV upload as K-Means training set
  • Trend and pollution distribution charts
  • ML prediction with estimated AQI
